# anovakun

井関龍太氏による分散分析関数「ANOVA君」(anovakun)を，R パッケージとしてインストールできる形にまとめるためのリポジトリです。

- 作者：井関龍太(大正大学)
- 保守：小杉考司(専修大学)
- 本家：https://riseki.cloudfree.jp/?ANOVA%E5%90%9B

分析の計算そのものは本家の ANOVA君に手を加えず，パッケージの体裁を整えることだけを行います。出力は本家と数値が一致することを確かめてから公開します。
